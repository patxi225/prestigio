Prestigio es una web de un restaurante de cocina italiana, desarrollada como proyecto del ciclo de Desarrollo de Aplicaciones Web (DAW).
En esta web puedes consultar la carta del restaurante, ver los detalles de cada plato, seleccionar ingredientes extra y añadir productos al carrito para realizar pedidos.
El proyecto está desarrollado utilizando HTML, CSS, Bootstrap y PHP, con una base de datos MySQL gestionada mediante Docker.
El objetivo es crear una web funcional y sencilla de utilizar, con un diseño inspirado en los restaurantes italianos de lujo.
